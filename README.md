## 🛡️ 長輩同行三大核心升級重點

1. **交通全面換成「計程車／Kakao T 門對門」**：
   - 釜山地鐵站普遍深且許多出入口無手扶梯，4 人搭計程車分攤車資與地鐵相近，且直接送到景點平坦入口，每天為長輩省下至少 15,000 步爬階負擔。
   - 機場往返有 4 個大行李箱，用 Kakao T 叫 **「벤（Venti / 大型車）」**；平日市區景點往返只帶隨身包，叫一般**「中型計程車」**即可。

2. **四大山海景點「長輩無痛走法」秘技**：
   - **甘川洞文化村**：計程車直達最頂端諮詢處（감천문화마을 안내센터），只走平緩主街看小王子與海景，原路折返，**絕對不要下切縱向陡階梯**。
   - **白淺灘文化村**：計程車停上方「絕影路（절영로）」，走上層平路看海選景觀咖啡廳，**嚴禁走鋼琴階梯下海邊步道**。
   - **龍頭山公園／釜山塔**：**計程車可直接開上山頂圓環停車場！**直接坐電梯登塔，避開光復路「只能上不能下」的單向手扶梯與回程陡下階梯。
   - **松島龍宮雲橋**：下切至雲橋有長鐵梯，若長輩當天腳痠，可在空中花園與松島海灘天空步道（全平路木棧道）散步拍照即可。

3. **6 大【激推】名店免久站排隊策略**：
   - **釜山宅**（17:00 開門準時到，首輪入座免排隊，店員全烤好上桌）。
   - **百花烤腸**（改排在 12:00 中午營業時吃，避開晚上大排長龍，阿姨桌邊現烤）。
   - **Bujebi 海鮮刀削麵**（西面暖胃蛤蜊高湯麵疙瘩搭軟嫩五花包肉，長輩接受度 100%）。
   - **海雲台 31cm 刀削麵**（水族館旁平路抵達，滿滿貝類海鮮精華湯頭）。
   - **Durumi Gwangan 燒肉**（煙火節 20:30 先以 CatchTable APP 線上取號，21:00 主秀後享用熱騰騰熟成烤肉慶功宴；傍晚沙灘先以 OPS 點心與保溫瓶熱水野餐防寒）。
   - **味贊王鹽烤肉**（由店員全程代烤，可用 CatchTable 國際版先線上取號）。
